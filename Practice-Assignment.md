# 📝 Practice Quiz – Solving Programming Challenges

### 1. What will you typically need to implement yourself in the programming assignments if you program in C++, Java or Python?

- **A.** Just writing the output.

- **B.** Just reading the input.

- **C.** Reading input, writing output and the solution to the problem.

- **D.** Just the solution of the problem.

✅ **Correct Answer:** **D. Just the solution of the problem.**

---

### 2. Your program in C, C++ or Java thinks that the product of numbers 50000 and 50000 is equal to −1794967296. What is the most probable reason?

- **A.** The input data is incorrect.

- **B.** The problem statement is wrong.

- **C.** Integer overflow.

- **D.** Compiler error.

✅ **Correct Answer:** **C. Integer overflow.**

---

### 3. Which tests should you perform before submitting a solution to the programming assignment?

- **A.** Just check that the answers for the examples from the problem statement are correct.

- **B.** Test on the examples from the problem statement. Then make a few other small tests, solve them manually and check that your program outputs the correct answer. Generate a big input and launch your program to check it works fast enough and doesn't consume too much memory. Test for corner cases: smallest and largest allowed values of input parameters, equal numbers in the input, very long strings, etc. Then make a stress test. After all these tests passed, submit the solution.

- **C.** Just submit the program and see if it passes the assignment.

- **D.** Test on the examples from the problem statement. Then make a few other small tests, solve them manually and check that your program outputs the correct answer. After all these tests passed, submit the solution.

✅ **Correct Answer:** **B. Test on the examples from the problem statement, perform additional small tests, large-input tests, corner-case tests, and stress tests before submitting the solution.**

---

### 4. Where does the input data come from when you implement a stress test?

- **A.** You generate valid input data as a part of the stress test implementation.

- **B.** You enter the input data manually.

- **C.** You download and use the tests we've prepared to check your solution to the problem.

✅ **Correct Answer:** **A. You generate valid input data as a part of the stress test implementation.**

---

### 5. If you submit a solution to a programming assignment, but it does not pass some of the tests, what feedback will you get from the system?

- **A.** If it is one of the first few tests, you will see the input data, the answer of your program and the correct answer. Otherwise, you will only see either that the answer of your program is wrong or that your program is too slow or that your program uses too much memory.

- **B.** You will see the input data, the answer of your program, the correct answer, how long did your program work and how much memory did it use for each of the tests.

- **C.** You will only get the feedback that your program either passed or did not pass.

✅ **Correct Answer:** **A. If it is one of the first few tests, you will see the input data, your program's answer and the correct answer. Otherwise, you will receive feedback indicating whether the answer is wrong, the program is too slow, or it uses too much memory.**
